1. Speed up system calls

uptime() could also be accelerated using a read-only shared page. The kernel could update the tick count in the shared page, allowing user programs to read it without entering the kernel.

2. Print a page table

Page 0 contains the init program's code and data. Page 2 contains the user stack. Page 1 is the stack guard page; because its PTE does not contain PTE_U, a user-mode process cannot read or write it. The third-to-last page is the read-only USYSCALL page, which contains the process PID.
